Abstract

Colormaps translate scalar data into visual structure, yet equal numerical steps often produce unequal perceptual differences. ColorMetric studies this mismatch and constructs uniformized colormaps by reparameterizing their color trajectories with a perceptual color-difference metric. The resulting maps preserve the original color path and endpoints while distributing perceptual change more consistently. This page provides an interactive gallery for exploring the effect and reusable color coordinates for reproducible visualization.
